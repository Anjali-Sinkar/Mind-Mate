Optional local music files (override the online streams)
==========================================================

Place MP3 files in this folder using these exact names:

  calm_meditation.mp3   -> Calm meditation
  rain_ambient.mp3      -> Rain ambient
  morning_garden.mp3    -> Morning garden

If a file exists, the Music therapy page will use it instead of the remote URL.
You can use royalty-free tracks from Pixabay, Mixkit, Free Music Archive, etc.

No files are bundled in the repo; add your own MP3s if you prefer full control.
